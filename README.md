# AI Workplace Companion

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant using React and Tailwind CSS.

Design: Clean, professional dashboard using buttermilk cream (#F7F0D5) and midnight blue (#14213D), with elegant typography, rounded cards, subtle shadows, clear icons, and a collapsible sidebar. Ensure mobile responsiveness.

Features:

AI Task Planner: Users enter tasks, deadlines, priorities, and available hours. Generate personalised weekly schedules, prioritise urgent and important tasks, and allow users to edit, complete, and delete tasks.

AI Research Assistant: Accept topics, pasted articles, or website URLs. Generate structured summaries, key insights, recommendations, and action points.

AI Chatbot: Interactive workplace assistant for writing emails, brainstorming, problem-solving, meeting summaries, and productivity advice. Provide contextual, specific responses based on user input.

Dashboard: Sidebar navigation, overview cards, upcoming tasks, weekly schedule, quick actions, and a polished chat interface.

AI behaviour: Use structured prompts that analyse user inputs before generating relevant, detailed outputs. Avoid generic responses. Make all generated outputs editable and copyable.

Technical requirements: Frontend only, no backend, database, authentication, or paid integrations. Use local sample data and browser localStorage for persistence. Implement working frontend interactions and clearly label any simulated AI features. Do not pretend real AI processing or URL analysis works without an API.

Responsible AI: Display a disclaimer explaining that AI outputs may contain errors and should be reviewed before professional use.

Prioritise a functional, polished MVP. Keep the implementation lightweight and avoid unnecessary features.
