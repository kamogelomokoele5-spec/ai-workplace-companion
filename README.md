# AI Workplace Productivity Assistant

## 1. Project Overview

The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals improve workplace productivity by organising tasks, conducting research, and receiving assistance with everyday work-related activities.

The application provides three main tools: an AI Task Planner, an AI Research Assistant, and an AI Chatbot. These features aim to simplify task management, support informed decision-making, and reduce the time spent on routine workplace activities.

The application uses a clean, professional dashboard design with a buttermilk cream and midnight blue colour palette. It is designed as a frontend-only application without a backend or database.

## 2. Features Implemented

### 2.1 AI Task Planner
- Allows users to organise and manage workplace tasks.
- Supports task prioritisation based on urgency and importance.
- Helps generate weekly schedules.
- Allows users to edit, complete, and delete tasks.
- Displays tasks in an organised dashboard.

### 2.2 AI Research Assistant
- Accepts research topics, pasted articles, and website URLs as inputs.
- Provides structured summaries, key insights, and recommendations where supported.
- Organises information into clear, readable sections.
- Allows users to edit and copy generated outputs.

*Note: Actual website analysis and AI-generated research require a working AI integration. Without an API, these functions may be demonstrated using sample or simulated responses.*

### 2.3 AI Chatbot Interface
- Provides a workplace assistant interface.
- Supports workplace-related prompts, including email writing, brainstorming, meeting summaries, and problem-solving.
- Presents responses in a conversational format.
- Allows users to copy and edit responses.

*Note: Genuine AI chatbot responses require an AI model integration. Simulated responses may be used in the frontend demonstration.*

### 2.4 Dashboard and User Interface
- Modern dashboard with sidebar navigation.
- Responsive layout for desktop, tablet, and mobile devices.
- Buttermilk cream and midnight blue colour scheme.
- Overview cards and quick-access features.
- Editable outputs and intuitive interactions.
- Local browser storage for supported data persistence.

### 2.5 Responsible AI
- Displays a responsible AI disclaimer.
- Reminds users to review AI-generated information before using it professionally.
- Acknowledges that AI outputs may contain inaccuracies.

## 4. Setup Instructions

### 4.1 Prerequisites

Before running the project, ensure that you have:

- A web browser such as Google Chrome.
- Access to the Lovable platform.
- Node.js and npm installed if running the exported project locally.
- A code editor such as Visual Studio Code if editing the source files locally.

### 4.2 Run the Application Using Lovable

1. Open [Lovable](https://lovable.dev/).
2. Open the AI Workplace Productivity Assistant project.
3. Allow the application preview to load.
4. Test the dashboard, task planner, research assistant, and chatbot.
5. Verify that supported task changes are saved in browser localStorage.

### 4.3 Run the Application Locally

1. Export or connect your Lovable project to a local development environment.
2. Download the project files and open the project folder in Visual Studio Code.
3. Open a terminal in the project directory.
4. Install the project dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in the terminal, commonly `http://localhost:5173`.

*Note: The exact commands and local URL may differ depending on the generated project configuration.*

## 5. Application Limitations

- The application does not use a backend or database.
- Browser localStorage stores data locally and does not synchronise it across devices.
- Real AI-generated responses require an integrated AI model or API.
- Website URL analysis requires a supported retrieval or browsing mechanism.
- Simulated AI responses should not be represented as genuine AI-generated results.

## 6. Responsible Use

The application is intended to support workplace productivity and decision-making. Users should verify important information, protect confidential workplace data, and review generated content before relying on it.

**Disclaimer:** AI-generated outputs may contain errors, incomplete information, or inaccurate recommendations. Users remain responsible for reviewing and validating the information before professional use.

## 7. Conclusion

The AI Workplace Productivity Assistant demonstrates how AI-assisted development can be applied to common workplace challenges. By combining task planning, research support, and conversational assistance in one responsive interface, the application provides a foundation for improving organisation and productivity.

The project can be extended in the future with genuine AI integration, advanced scheduling, document exports, and secure cloud-based data storage.
